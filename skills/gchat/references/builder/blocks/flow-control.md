# Builder-блоки: управление потоком

Общий контракт графа и source handles — в [builder.md](../../builder.md). Триггеры и условные выходы описаны в [отдельном справочнике](../triggers-and-conditions.md).

## `stop_automation`

Блок без дополнительных полей. Завершает текущую автоматизацию для текущего клиента. Не добавляй к нему выдуманные параметры.

## `stop_funnels`

Поле `funnelIds[]` содержит UUID других builder-автоматизаций, которые нужно остановить для клиента. Найди их через `automations_list` в нужных пространствах и сверь ID через MCP; не подставляй display name. Пустой массив — no-op.

## Завершение ветки и stop-блоки

Ветка, у которой нет исходящего ребра, просто заканчивается. Используй `stop_automation`, если в графе нужно явно остановить текущий run; используй `stop_funnels`, если нужно остановить другие перечисленные автоматизации. Не путай это с выключением самой автоматизации: внешнее состояние `enabled` меняется только инструментами `automation_enable` и `automation_disable`.
